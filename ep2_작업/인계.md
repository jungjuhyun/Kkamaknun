# 인계 — 까막눈 2편 기획 (2026-09-30)

이 파일은 새 채팅에서 2편 기획을 이어 가기 위한 요약이다. 이 파일 하나만 읽어도 이어서 일할 수 있게 썼다.

자세한 근거는 같은 폴더의 다른 파일에 있다(맨 아래 "파일" 표).

## 1. 채널 기본 (채널 문서에서 가져옴)

- 까막눈: 애니를 20년 넘게 보며 귀로만 일본어가 쌓인 사람이, 일본 문화를 더 즐기려고 일본어를 배우는 채널. 청해만 앞서 있고 글자·문법·말하기는 거의 없다.
- 본체는 애니·여행·일본 문화·현지 경험이다. 일본어는 목적이 아니라 도구다.
- 강의 채널이 아니다. 기본 태도는 "이게 필요해서 이렇게 해 봤고, 실제로는 이렇게 됐다"이다.
- 사람들이 보는 이유: 이 사람이 다음에 일본과 관련해 무엇을 해 보고 어디까지 가는지 궁금해서. 비슷한 수준의 사람이 "나도 할 수 있겠다"를 느껴서.
- 기획 도구 A/B→C: A 누가(맥락 붙인 사람), B 무엇을(수·시간·장소·방법·상대를 바꿔 넓힘), C 보고 나서 남는 느낌.
- 실험형 3기준: 결과를 모른다, 남이 안 해봤다, 까막눈이라 생긴다.
- 여행처럼 비용·시간이 큰 형식은 2027년 9~12월 이후에 한다.
- 만드는 사람: 낯선 사람을 계속 상대하는 인터뷰·라이브는 하지 않는다. 카메라를 의식하며 행동을 바꾸는 것을 싫어한다. 연출된 성공·실패·반응을 매우 싫어한다. 밈·병맛·상황극과 잘 맞는다. 개발자 출신이다. 료칸·온천·소도시·교토, 오래된 골목과 건물을 좋아한다. 일본에 가 본 적은 없다.

## 2. 1편 결과 (2편의 출발점)

1편: 체인소 맨 레제편을 자막 없이 보고 얼마나 들리는지 확인했다. 판정은 Claude가 했고 사용자 확인 전이다.

| 항목 | 결과 |
|---|---|
| 대사에 반응한 줄 | 385줄, 맞음 75% |
| 8자 이하 짧은 대사 | 91% 맞음 |
| 16자 이상 긴 대사 | 62% 맞음 |
| 동사 끝에 붙는 말 0~1개 (9자 이상 대사) | 76% 맞음 |
| 동사 끝에 붙는 말 2개 이상 (9자 이상 대사) | 58% 맞음 |
| 막힌 36줄 중 동사 끝 모양이 든 줄 | 29줄 |

진단 한 줄: 단어와 짧은 말은 이미 귀에 있다. 동사 끝 모양(동사 활용)이 비어 있다. 그래서 泳ぎ(오요기, 수영)는 영화 안에서 스스로 알아냈지만 泳げない(오요게나이, 수영 못 한다)는 놓쳤다.

문법별로 맞음이 낮은 것 (교재 『민나노 니홍고 초급』 과):

| 문법 | 1편 줄 수 | 맞음 | 교재 과 |
|---|---|---|---|
| ~할 수 있다 (가능형) | 33 | 48% | 27과 |
| 안 ~ (ない형, 나이) | 64 | 58% | 17과 |
| ~했다 (た형, 타) | 62 | 58% | 19과 |
| ~하면 (たら·ば, 타라·바) | 22 | 64% | 25과, 35과 |
| ~하고·~해서 (て형, 테) | 84 | 67% | 14과 |

## 3. 사용자가 정한 원칙

| 원칙 | 이유 |
|---|---|
| 후보마다 첫 질문은 "채널을 전혀 모르는 사람이 이 영상을 왜 보는가"다. 한 줄로 답 못 하면 A/B→C를 짜지 않는다 | 만드는 사람의 문제는 보는 사람의 궁금증이 아니다 |
| 실력을 재는 편(실험 카메라)은 중간중간만 넣는다. 연달아 넣지 않는다 | 연달아 넣으면 실험 카메라 채널이 된다 |
| 재는 방식(리뷰형)은 1편으로 충분하다 | 1편은 신기해서 보지만, 다음 편까지 같은 방식이면 안 본다 |
| "카타카나를 못 읽었다" 같은 것은 소재가 아니다 | 아무도 궁금해하지 않는다 |
| 2편은 진단 + 공부 + 확인이다. 애니 장면은 "이런 모양이 나오면 헷갈려서 못 알아듣는다"를 보여 주는 예시다. 공부는 사용자가 따로 한다 | |
| 일본어를 쓸 때는 옆에 한글 읽는 법을 붙인다. 예: 泳げない(오요게나이). 긴소리는 "오오·요오"처럼 쓴다 | 사용자가 아직 글자를 못 읽는다 |
| 아이디어는 후보로만 낸다. 고르는 것은 사용자다 | |
| 후보를 내기 전에 수요(검색량, 작은 채널의 높은 조회수)와 공급(비슷한 영상 수, 최근에도 올라오는지)을 먼저 센다 | 수요·공급을 안 보고 낸 아이디어는 근거 없는 아이디어와 같다 (2026-09-30 사용자 지적) |
| 수요가 있는 주제를 먼저 찾고, 그 안에서 까막눈이 할 것을 고른다. 수요가 없는 후보는 정말 새로운 것일 때만 낸다 | 수요가 없으면 만들 이유가 없다 (2026-09-30 사용자 지적) |
| 돈이 드는 작업(API 등)은 먼저 비용을 말하고 묻는다 | |
| 1편 작업 폴더(`ep1_작업/`, `channel_ep1.md`)는 고치지 않는다 | 다른 채팅에서 작업 중 |

## 4. 지금 살아 있는 안

### 2편 기획 초안 (`기획.md`)

| 칸 | 내용 |
|---|---|
| 모르는 사람이 보는 이유 | 애니를 오래 본 사람은 "대충 알겠는데 정확히는 모르겠다"를 겪는다. 원인을 찾고, 고쳐 보고, 정말 나아졌는지 끝까지 확인한다 |
| A | 애니만 20년 봐서 짧은 대사는 91% 알아듣지만, 동사 끝이 붙으면 58%로 떨어지는 사람 |
| B | 막히는 동사 끝 모양을 따로 공부해 익숙해진 뒤, 못 들었던 장면과 처음 보는 영상을 자막 없이 다시 본다 |
| C | 막힌 곳을 알고 고치니 이만큼 달라진다. 또는 생각보다 안 달라진다 |

흐름: 1편 "몰라" 장면으로 시작 → 진단(91%와 58%) → 예시 장면 → 공부 타임랩스와 중간 확인 → 1편 장면 다시 보기 → 처음 보는 영상 → 결과와 다음 약점.

예시 장면(1편): 泳げない(오요게나이), 食えて(쿠에테), 触らないよう(사와라나이요오), しか来ない(시카 코나이), 襲われてます(오소와레테마스), 殺しすぎてる(코로시스기테루).

아직 정할 것: 공부 기간(기본안 2주, 짐작), 확인에 쓸 처음 보는 영상, 1편과의 순서(1편 공개 시기 미정).

### 공부 순서 (`커리큘럼.md`, 영상 순서가 아니라 영상 밖 공부 순서)

0 히라가나·가타카나(영상 밖) → 동사 끝 모양(14·17·19·27과) → 반말·줄인 말(20과 + 교재 밖 보충) → 단어 → 나머지 동사 모양(25·29·35·36·37·44·48과) → 긴 문장. 조사는 다른 공부에 끼운다.

### 재지 않는 편 — 줄기 두 개 (`브레인스토밍.md` 2차·3차)

사용자 평가: 1차 후보 12개 중 "일본 요리 따라 만들기"는 약하니 "한국에서 일본 분위기가 물씬 나는 장소 가기"로 바꾼다. "AI 회화 앱과 대화"는 그럴듯하다. 나머지(자막 번역 비교, 애니송 노래방, 더빙, 일본판 만화, 굿즈 직구, 하루 일본어만)는 남기지 않았다.

- 줄기 A 한국 속 일본: 장소에 가서 배운 것을 써 보는 리허설.
- 줄기 B AI 일본인과 대화: 공부 진도에 따라 대화가 달라진다. 직접 만들 수도 있다(API 비용은 먼저 묻기).
- 흐름: AI와 연습 → 한국 속 일본에서 리허설 → 중간중간 재는 편 → 2027년 9월 이후 일본 여행.

서울 속 일본 (웹 검색으로 확인):

| 종류 | 장소 | 걸리는 점 |
|---|---|---|
| 일본식 찻집 | 문래 킷사고구마 (일본인 사장, 일본어 메뉴판) | 사장과 짧게 말을 나눔 |
| 일본식 가옥 카페 | 용산 청파동 킷테 (1930년 가옥), 후암동 언뎁트 | 일제강점기 흔적이라 역사 논란 댓글 가능 |
| 밥집·이자카야 | 성수 신기루야, 연희 희로 | |
| 동네 | 동부이촌동 "리틀 도쿄", 용산 후암동·원효로 | 후암동은 역사 논란 가능 |
| 문화 공간 | 주한일본대사관 공보문화원 (종로, 도서실 약 22,000권, 1월·7월 전시) | |
| 목욕 | 도미인 서울 강남 사우나 | 투숙객 외 이용 조건 확인 안 함 |
| 덕질 | 홍대·연남 가챠샵, 홍대 애니 굿즈샵, 북새통문고 | |
| 행사 | 더현대 서울 애니 팝업(계속 새로 열림), 한일축제한마당 2026 (10월 10일 토, 코엑스, 무료) | |

서울 밖: 구룡포·군산·목포 일본식 가옥 거리, 부산 감천문화마을·초량 이바구길, 국내 료칸(남해 토모노야, 부산 기장 호시카게, 거제 덴바스타, 양평 길조 호텔). 료칸은 숙박비가 커서 자주 못 간다.

찾지 못한 것: 서울 다도·기모노 체험 수업.

비슷한 채널: 유튜버 센님(애니 독학 3년 만에 JLPT N1, 구독 26만, 책 출간). 까막눈이 다른 점은 진행 중인 과정, 1편부터 숫자 기록, 개발자라 도구를 직접 만든다는 것.

편 수 짐작(주 1편 가정): 2026년 10월~2027년 8월 약 48편 필요. 재는 편 약 10 + 한국 속 일본 약 15~25 + AI 대화 약 10. 아직 모자랄 수 있다.
