# JM 영상 분석 (2026-10-01)

채널: JM (@jmjm, 구독자 60.8만). 일본에 사는 한국인이 혼자 찍는 채널.

자료: 목록 30개 중 자막이 있는 23개의 자동 자막(사용자 컴퓨터에서 받음). 조회수는 2026-10-01 채널 페이지 기준.

목적: 안원잘부(여러 명 채널)와 같은 칸으로 보고, 혼자 찍는 채널에도 같은 장치가 있는지 찾는다.

## 한계

- 자막에는 말만 있다. 화면 자막, 효과음, 컷 전환은 안 보인다.
- 일본어로 말하는 영상(리에 시리즈 3개, 지하 아이돌, 룸투어, 프로배우)은 일본어 자동 자막이라 받아쓰기가 많이 틀렸다. 흐름만 읽었다.
- 2016~2020년 영상의 한국어 자동 자막도 많이 틀렸다.
- 조회수는 올린 뒤 쌓인 값이다. 최근 4개월 영상은 쌓인 기간이 짧다.
- 7개(자전거 1일차·마지막 편, 사진집, 란도셀, 네일샵, 지하 아이돌 은퇴, 지하 아이돌에 쏟아붓는 오타쿠)는 자막이 없어 못 봤다.
- 「프로배우 vs 일반인 남자친구」(87만)는 성인 배우 인터뷰라 장치 표에서 뺐다.

## 3. 사용자 느낌과 맞춰 보기

| 사용자 느낌 | JM에서 | 판정 |
|---|---|---|
| 1 그냥 형식 | 모든 영상이 체험 브이로그 형식 | 맞음 |
| 2 A가 B를 한다 | 모든 영상. 예: JM이 택시로 부산까지 간다 | 맞음 |
| 3 C 감상을 준다 | 체험형은 끝에 숫자·가성비 결론, 사람형은 끝에 진심 토크 | 맞음. 감상이 두 종류로 나뉨 |
| 4 다른 장르가 한 번 섞인다 | 캡슐호텔 리뷰에 지진 실화, 인력거 체험에 사람 이야기(휴먼 다큐), 오타쿠 취재에 하루 밀착 | 일부 맞음 |
| 4의 예외 | 1위 택시(505만)는 섞인 장르가 약하다. 질문 하나와 올라가는 미터기 숫자로 끝까지 감 | 예외 있음 |
| 느낌에 없던 것 | 질문 하나의 힘. 그리고 계획이 틀어지는 사고 | 새로 보임 |

같은 소재 비교: 캡슐호텔 1박은 두 번 찍었다. 지진이 섞인 편 163만, 안 섞인 편 125만이다.
그런데 찍은 해가 달라서(4년 전, 9년 전) 섞임 하나로 차이를 설명할 수는 없다.

최근 3주 영상 비교: 찬물 컵라면 20만, 소개팅 8.6만이다.
소개팅은 참가자가 일반인이라 대화 장면을 못 찍었다고 본인이 말한다. 그래서 사람 반응 장면이 없다.
컵라면은 품절·폭우·젓가락 없음이 화면에서 터졌다.

## 4. 안원잘부와 나란히

| 장치 | 안원잘부 (여러 명) | JM (혼자) |
|---|---|---|
| 실제 사람 반응 | 있음 | 있음 |
| 같은 사람·관계가 편을 넘어 이어짐 | 있음 (멤버) | 있음 (리에, 게스트 1명) |
| 진심 토크 | 있음 | 있음 |
| 조회수 약속 | 있음 ("20만 넘으면 파인다이닝") | 있음 ("평균 30만 넘으면 항공권") |
| 문화 비교 토크 | 있음 (갸루 편) | 있음 |
| 캐릭터 연기 | 있음 | 없음 |
| 게임 규칙 | 있음 | 못 봄 |
| 대결 | 있음 | 못 봄 |
| 뿌리 찾기 | 있음 | 없음 |
| 궁금한 질문이 곧 제목 | 분석표에 안 적음 | 있음 |
| 숫자로 끝냄 | 분석표에 안 적음 | 있음 |
| 계획이 틀어짐 | 분석표에 안 적음 | 있음 |

"분석표에 안 적음"은 안원잘부에 없다는 뜻이 아니다. 안원잘부를 볼 때 그 칸으로 보지 않았다는 뜻이다.

가장 높은 구간을 만든 것은 두 채널이 다르다.
안원잘부는 캐릭터·관계가 생긴 뒤 451만~1,497만으로 올랐다.
JM은 혼자 찍은 택시(505만)가 2위 침대기차(212만)의 2배가 넘는다. 리에 시리즈(85만~171만)는 혼자 찍은 체험 영상(97만~212만)과 비슷한 높이다.
JM도 게스트 1명(리에)을 반복해 내보내며 관계 장치를 썼지만, 조회수를 크게 끌어올리지는 않았다.

## 5. 까막눈과 닿는 점

- 오타쿠 축제(170만)에서 JM은 "우리가 애니메이션을 많이 안 봐서 어떤 작품인지 모른다"고 말한다. 작품을 아는 눈이 이 영상에 없다.
- 리에는 한국어를 공부하는 일본인이다. 지하철에서 TWICE 영상을 0.5배속으로 보며 공부한다고 말한다. 까막눈과 거꾸로인 사람이 화면에 나오면 문화 비교 토크가 생겼다.
- 리에를 고른 방법은 검색이었다. "검색했을 때 한국 영상에 안 나온 새 얼굴"을 골랐다고 JM이 마지막 편에서 말한다.
