## 3. 판정

수요가 큰 관심사는 넷이다: 일본 노래, 일본 방송·반응, 일본인 친구, 영화·애니.

넷 모두 까막눈이 한국에서 할 수 있다. 다만 넷 모두 걸리는 점이 하나씩 있다.

| 관심사 | 걸리는 것 |
|---|---|
| 일본 노래 | 사용자가 뺀 방향 |
| 일본 방송·반응 | 공급이 이미 너무 많음 |
| 일본인 친구 | 사용자 성향 |
| 영화·애니 | 공급이 많음, 저작권 |

그래서 어느 걸리는 점을 받아들일지는 사용자가 정한다.

## 확인하지 못한 것

- 네이버 검색량(데이터랩 API 키 필요, 무료).
- "일본 이름"(구글 51)은 왜 찾는지 확인하지 못했다.
- 구독자 수는 채널 이름으로 찾아서 다른 채널과 섞였을 수 있다. 예: 「애니트립」은 구독 345명에 225만 회로 나와 표에서 뺐다.
