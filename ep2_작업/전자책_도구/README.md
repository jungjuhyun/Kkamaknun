# 전자책 편집 도구

오레노 니홍고 전자책의 일본어 쪽을 "빨강 읽는 법 · 검정 일본어 · 주황 한글 소리 · 초록 뜻" 세로 편집본으로 만드는 도구다.
책 내용(뽑은 글, 편집본, 원고 txt)은 저장소가 공개라서 올리지 않는다. 이 폴더에는 코드만 둔다.

## 순서

| 단계 | 파일 | 하는 일 |
|---|---|---|
| 1 | `pm_extract.py` | 나눈 PDF에서 글자마다 글꼴·번호·위치를 뽑는다 |
| 2 | `decode.py` | 깨진 글자 번호를 글꼴 그림과 맞춰 진짜 글자로 바꾼다 |
| 3 | `rebuild.py` | 세로 줄 단위로 쪽 글을 다시 짠다 |
| 4 | (사람·Claude) | 쪽 글을 원고 txt로 쓴다: 읽는 법 `{漢字|よみ}`, 덩어리 ` / `, 뜻 `일본어=한국어` |
| 5 | `build.py` | 원고 txt → html (`split_ruby.py`로 한자마다 읽기 나눔, `kana2hangul.py`로 한글 소리) |
| 6 | `shot2.js` | html의 쪽마다 png로 찍는다 (Playwright) |
| 7 | `쪽합치기.py` | png를 원래 책 쪽 자리에 넣어 157쪽 PDF 하나로 만든다 |

## 원고 txt 모양

- `@ 제목` 섹션 제목, `# 15쪽` 쪽 나눔
- `*`로 시작하면 제목 줄, `~`로 시작하면 주석 줄, 빈 줄은 간격
