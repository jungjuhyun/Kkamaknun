# 2편 아이디어 후보

이 파일은 2편 후보를 모은다. 무엇을 할지는 사용자가 고른다.

용어(A/B→C, 핵심 장면, 실험형 3기준, 보는 사람, 입구를 넓힌다)는 `../channel_howtomake.md`에 있다.

1편에서 막힌 줄 목록은 `1편_막힌곳.md`에 있다.

## 후보를 거르는 첫 질문

> 채널을 전혀 모르는 사람이 이 영상을 왜 보는가.

이 질문에 한 줄로 답하지 못하면 A/B→C를 짜지 않는다.

1편을 안 본 사람도 제목과 첫 장면만으로 볼 이유가 생겨야 한다. 1편의 숫자나 장면은 영상 안의 재료로만 쓴다.

## 탈락한 후보 (2026-09-29)

| 후보 | 모르는 사람 눈에 보이는 것 | 볼 이유가 없는 까닭 |
|---|---|---|
| 1편 오답 다시 듣기 | 모르는 사람이 모르는 영화 대사를 다시 듣는다 | 1편을 봐야만 궁금하다 |
| 가나 익히고 다시 읽기 | 가나를 외운다 | 같은 영상이 흔하다. "22초"는 1편을 안 보면 뜻이 없다 |
| 일본어 자막 켜고 보기 | 글자를 못 읽는 사람이 일본어 자막을 켠다 | 못 읽는다는 결과가 뻔하다 |
| 해독형 本部庁舎 | 한자 하나를 풀어 준다 | 일본어 공부하는 사람만 본다. 강의처럼 보인다 |

탈락 원인: 1편에서 막힌 곳을 그대로 영상으로 옮겼다. 막힌 곳은 만드는 사람의 문제이고, 보는 사람의 궁금증이 아니다.

## 탈락한 후보 가·나·다 (2026-09-29)

사용자 지적: 셋 다 "자막 없이 보고, 얼마나 되는지 잰다"는 리뷰 방식이다. 재는 것은 1편으로 충분하다.

아래는 기록으로만 남긴다. 아래 후보는 모두 "남이 안 해봤다"를 검색으로 확인하지 않았다.

### 후보 가. 애니로 배운 일본어는 현실에서도 들릴까

| 칸 | 내용 |
|---|---|
| 모르는 사람이 보는 이유 | 애니를 많이 본 사람은 누구나 "나 애니 일본어는 좀 알아듣는데, 진짜 일본에서도 통할까?"가 궁금하다 |
| 한 줄 | 애니 대사는 74% 알아들은 귀, 일본 현지 영상에서는 몇 %? |
| A | 공부 없이 애니만 20년 본 사람 |
| B | 일본 사람이 찍은 교토·료칸·온천 여행 영상을 자막 없이 본다 |
| C | 애니 일본어와 현실 일본어는 이만큼 다르다. 또는 생각보다 통한다 |

- 본체와 이어짐: 사용자가 가고 싶은 교토·료칸·온천이다. 2027년 여행까지 이어지는 준비가 된다.
- 약점: 1편과 같은 "자막 없이 보기" 모양이다. 반복감이 생길 수 있다.
- 약점: 남의 영상을 쓴다. 저작권을 따로 풀어야 한다.

### 후보 나. 공부 0, 애니 20년이면 JLPT 몇 급일까

| 칸 | 내용 |
|---|---|
| 모르는 사람이 보는 이유 | JLPT 급수는 일본어를 안 해도 아는 기준이다. "애니만 봐도 자격증 나오나?"는 애니 보는 사람 누구나 한 번쯤 한 생각이다 |
| 한 줄 | 애니만 20년 본 사람이 JLPT를 풀면: 듣기는 몇 급, 글자는 몇 급? |
| A | 듣기만 앞서고 글자는 거의 못 읽는 사람 |
| B | JLPT 공식 문제 예시를 급수별로 푼다. 듣기와 글자 문제를 나눠서 본다 |
| C | 듣기와 글자의 급수가 이만큼 벌어진다. 그게 까막눈이다 |

- 까막눈이라 생긴다: 듣기와 글자 급수가 크게 벌어지는 사람은 드물다.
- 약점: 비슷한 영상이 있을 가능성이 높다. 검색 확인이 먼저다.
- 약점: 문제 푸는 화면은 밋밋해지기 쉽다. 틀리고 맞히는 순간의 반응이 받쳐 줘야 한다.

### 후보 다. 어릴 때 더빙으로 본 애니, 원래 대사는 뭐였을까

| 칸 | 내용 |
|---|---|
| 모르는 사람이 보는 이유 | 한국 사람 대부분이 더빙 애니(원피스, 짱구, 포켓몬 같은 것)를 보고 자랐다. "그 장면 원래는 뭐라고 했지?"는 애니를 안 보는 사람도 궁금하다 |
| 한 줄 | 20년 전 더빙으로 본 원피스 명장면, 공부 안 한 귀로 원어를 들으면 뭐가 달랐을까 |
| A | 원피스 더빙판으로 애니를 시작해 20년 동안 귀로만 일본어를 쌓은 사람 |
| B | 더빙으로 기억하는 명장면을 일본어 원판으로 보고, 들리는 대로 더빙과 비교한다 |
| C | 어릴 때 들은 그 대사가 원래는 이랬다. 추억과 실제의 차이 |

- 나에게 자연스러운가: 사용자가 애니를 시작한 작품이다. 장면에 감정이 붙어 있다.
- 약점: 더빙과 원판을 비교하는 영상은 이미 많을 가능성이 높다. 까막눈만의 각도는 "공부 안 한 귀로 차이를 잡는가"이다.
- 약점: 더빙판과 원판 두 가지 장면을 모두 쓴다. 저작권 부담이 가장 크다.

## 진단에서 출발한 후보 (2026-09-29)

사용자 방향: 내 상태를 진단하고, 막힌 곳을 풀려면 무엇을 공부해야 하고, 그걸 어떻게 콘텐츠로 만들지에 초점을 둔다. 실력을 재는 리뷰형은 1편으로 충분하다.

진단은 `진단.md`에 있다. 요약: 짧은 말은 91% 들리는데, 동사 끝에 붙는 말이 2개 이상이면 58%로 떨어진다.

### 후보 ㄱ. 애니를 20년 봐도 일본어가 "대충"만 들리는 이유

| 칸 | 내용 |
|---|---|
| 모르는 사람이 보는 이유 | 애니를 오래 본 사람은 "대충 알겠는데 정확히는 모르겠다"를 겪는다. 그 이유를 실제 기록으로 보여 준다 |
| 한 줄 | 애니 20년 본 귀에 없던 것: 단어는 있는데 동사 끝이 없었다 |
| A | 애니를 20년 봤고, 자기 듣기를 한 줄씩 기록으로 남긴 사람 |
| B | 1편 기록을 나눠 보고 어디서 막히는지 찾는다. 그걸 풀 공부 계획을 세운다 |
| C | 나도 그래서 대충만 들렸구나. 이 사람이 이제 뭘 할지 궁금하다 |

- 약점: 공부를 아직 안 한 상태라 "해 봤더니 이렇게 됐다"가 없다. 계획 발표로 끝난다.

### 후보 ㄴ. 동사 끝 하나만 익히면 애니가 더 들릴까

| 칸 | 내용 |
|---|---|
| 모르는 사람이 보는 이유 | "이것 하나만 하면 된다"는 말이 진짜인지 누가 대신 해 봐 준다 |
| 한 줄 | 애니 귀에 "~할 수 있다" 모양 하나를 넣었더니 |
| A | 단어는 들리는데 동사 끝에서 막히는 사람 |
| B | 동사 끝 모양 하나를 좋아하는 애니 대사로만 익힌다. 그 뒤 좋아하는 애니 새 화를 자막 없이 보고 그 모양이 들리는지 본다 |
| C | 모양 하나로 들리는 것이 이만큼 달라진다. 또는 생각보다 안 달라진다 |

- 반복: 모양마다 한 편씩 만들 수 있다.
- 약점: 반복하면 강의처럼 굳을 수 있다. "가르치기"가 아니라 "해 봤더니 이렇게 됐다"로 끝내야 한다.
- 약점: 마지막 확인이 "재기"다. 재는 부분은 짧게, 익히는 과정이 본체다.

### 후보 ㄷ. 좋아하는 장면 속 동사 하나의 모양 바꾸기 (확장형 시험)

| 칸 | 내용 |
|---|---|
| 모르는 사람이 보는 이유 | 좋아하는 장면의 대사를 이제야 정확히 알게 된다 |
| 한 줄 | 레제가 덴지에게 수영을 가르치는 장면: 泳ぐ가 모양을 바꾸면 뜻이 이렇게 바뀐다 |
| A | 泳ぎ는 영화 안에서 알아냈지만 泳げない는 놓친 사람 |
| B | 한 동사가 장면마다 모양을 바꾸는 대사를 모아 잇는다 (`../channel_format_decode.md`의 확장형) |
| C | 같은 단어가 끝만 바뀌어 뜻이 달라지는 것을 귀로 알게 된다 |

- 이 진단은 "해독형·반복형·확장형 중 무엇을 먼저 시험할지"에 답을 준다. 막힌 곳이 동사 끝이라 확장형이 맞다.
- 약점: 그 작품을 아는 사람에게만 열린다. 설명이 늘면 강의가 된다. 저작권.
